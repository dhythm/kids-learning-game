## Shared integration pattern
Both subjects follow the kanji integration pattern:
- Stage/level defs with ids, titles, descriptions; Home sections with cards showing best score (storage key = level id, no difficulty suffix).
- A drill screen with: progress x/10, live timer, score + combo via lib/scoring.ts, immediate feedback, auto-advance ~700ms, StrictMode-safe timers, large choice buttons (min-height 82px like others), light mode.
- Finish flow through App like kanji: saveResult(levelId, result), recordResult(levelId, result) for stats/badges, newly-earned badges on ResultScreen (reuse the generalised ResultScreen), missed questions go to the review list (see below).
- ParentReport: add sections for both subjects listing their stages when played (like the kanji section).
- Review mode extension: extend lib/review.ts item union with:
  - Clock: `{ kind: 'clock', levelId: string, hour: number, minute: number, missedAt: number }`, identity `clock:${hour}:${minute}`; toReviewQuestions rebuilds 4 time choices via the clock generator helpers, promptLabel = 'なんじ なんふん？' and the prompt needs the clock face — ReviewQuestion gains an optional `clock?: { hour, minute }` field, and ReviewDrillScreen renders the ClockFace component when present.
  - Money: `{ kind: 'money', levelId: string, coins: { denom: number, count: number }[], total: number, missedAt: number }`, identity `money:${total}:${coins signature}`; ReviewQuestion gains optional `money?: { denom, count }[]`, ReviewDrillScreen renders the MoneyVisual component when present; choices rebuilt via money distractor helper.
  Drill screens for clock/money pass missed items up exactly like math/kanji do after part A.

## 1. とけいドリル (src/lib/clock.ts, src/lib/clockQuestions.ts, src/components/ClockFace.tsx, ClockDrillScreen)
Stages:
- `clock-s1` 「○じと ○じはん」 — hour on the hour (minute 0) and half past (30) only. Hours 1..12.
- `clock-s2` 「15ふんずつ」 — minutes in {0, 15, 30, 45}.
- `clock-s3` 「5ふんずつ」 — minutes in multiples of 5.
Generator (pure, injectable RNG):
- `generateClockQuestion(stage, rng?)` -> `{ hour (1..12), minute, text: '3時15分' format (use formatTime(hour, minute): minute 0 -> '3時', 30 in s1 may be '3時30分' — keep one consistent format: '3時' when 0 else '3時○分'), choices: string[4] }` — 4 unique choices containing the answer; distractors: nearby times (±5/±15/±30 minutes, hour ±1) normalised to 12-hour clock, formatted the same way, and for s1 distractors stay within {0,30} minutes; s2 within quarter hours; s3 within 5-minute steps.
- `generateClockSet(stage, count = 10, rng?)` — no duplicate (hour, minute) pairs in a set when the stage's space allows (s1 space = 24, fine).
- `ClockFace` component: inline SVG analog clock — circle face, hour ticks (12, longer at 12/3/6/9), numerals optional (12,3,6,9 at least — or all 12 small), hour hand (short, thick) and minute hand (long, thin) rotated correctly (hour hand moves with minutes), center dot. Accessible: role="img" with aria-label like 「3時15分」… wait, that would give away the answer to screen readers; use aria-label="とけい" and aria-hidden for the hands' values; the question is a visual exercise. Size ~min(240px, 70vw).
- Drill screen shows ClockFace big, prompt 「なんじ なんふん？」, choices as text buttons.

## 2. おかねドリル (src/lib/money.ts, src/lib/moneyQuestions.ts, src/components/MoneyVisual.tsx, MoneyDrillScreen)
Denominations: coins 1, 5, 10, 50, 100, 500; bills 1000, 5000 (10000 not needed).
Stages:
- `money-s1` 「こうかだけ」 — coins only, 2..4 coins, total <= 300.
- `money-s2` 「こうか いろいろ」 — coins only, 3..6 coins, total <= 1000.
- `money-s3` 「おさつも いっしょ」 — bills (0..1 of 1000, rarely 5000 in hard? keep: 1000 bill 0..1, 5000 bill 0..1 but total <= 6000) + coins 2..5, total <= 6000.
Generator (pure, injectable RNG):
- `generateMoneyQuestion(stage, rng?)` -> `{ coins: { denom, count }[] (only count > 0, sorted desc by denom), total, choices: number[4] }` — choices unique, contain total, distractors plausible (±10, ±50, ±100, ±500, digit-slip like total±1 coin value), never negative, and for s1 stay within 0..500ish.
- `generateMoneySet(stage, count = 10, rng?)` — avoid duplicate totals more than twice per set if reasonably possible; at minimum no duplicate coin-combination signatures.
- `MoneyVisual` component: render each denomination as inline SVG/CSS — coins: circles with metallic-ish flat colours by denomination (1円 silver small … keep simple flat design: circle border + denomination number inside, size varies slightly), bills: rounded rectangles (green/blue tones) with 「1000円」 label. Show count by repeating the coin/bill elements (with a ×n badge if count > 3 to save space — simpler: repeat up to count, counts are small). Wrap in a flex area, responsive.
- Drill screen shows MoneyVisual, prompt 「ぜんぶで いくら？」, choices as 「○○円」 buttons (answer values formatted with 円 suffix in the button label; the underlying choice values are numbers).
