# kids-learning-game

子どもがブラウザで触って遊べる学習ゲーム。個人開発プロジェクト。

## コンセプト

- 対象：小学生（中心は小学5年生まで対応、年少向けのやさしいモードも用意する）
- 科目：まずは算数（たし算・ひき算・かけ算・九九・わり算、学年に応じたレベル）
- ゲーム性：タイムアタック、正解コンボ、レベルアップ、バッジなど、繰り返し遊びたくなる仕掛け
- 進捗はブラウザ内（localStorage）に保存し、サーバーなしで完結させる

## 技術方針

- Vite + React + TypeScript の静的サイト（GitHub Pages / Vercel 等の無料枠にデプロイ可能な形）
- 課金が発生する外部 API・サービスは使わない
- スマホ・タブレットでも遊べるレスポンシブ対応、タップしやすい UI
- UI はライトモード基調

## 開発の進め方

- 実装は Codex CLI（gpt-6.2-astra / Ultrafast）に委任し、成果物をレビューして取り込む
- 小さな単位でコミットし、main は常に動く状態を保つ
- テスト（問題生成ロジック等）と型チェックを通してからコミットする

## まず作るもの（v1）

1. トップ画面（モード選択）
2. 計算ドリル：学年別レベル、10問1セット、タイマー、スコア表示
3. 結果画面：正答率・タイム・コンボの表示、もう一度遊ぶ導線
4. 進捗保存：レベル別のベストスコア

## 遊び方 / 開発

- まちがえた算数・漢字は「ふくしゅう」で解き直せます。ホームには連続学習日数と今週の学習日が表示されます。

- 「かんじドリル」では、小学1〜3年の配当漢字（80字・160字・200字）を学年別に10問ずつ練習でき、ベストスコアは学年ごとに保存されます。
- レベルと難易度（やさしい・ふつう・むずかしい）をえらび、4択で10問に挑戦！ 正解は100てん、連続正解でコンボボーナス。ベストは難易度ごとにこのブラウザに保存されます。
- 全問正解や連続プレイでバッジを獲得！ 集めたバッジはホームで確認できます。
- ホームの「保護者向けレポート」で、挑戦回数や正答率、レベル・難易度ごとの学習記録を確認できます。

- 準備と起動：`npm install` → `npm run dev`
- テスト・型チェック：`npm test`、`npm run typecheck`
- 本番ビルド：`npm run build`（出力先は `dist/`）
